# V2.3.8

## Chart filling and scale ticks

- Partial pressure history now fills from left to right using fixed hourly
  positions.
- Increased the upper and lower Y-axis ticks from one to two pixels.
- Moved the Y-axis one pixel right, retaining a two-pixel gap between the tick
  ends and scale digits.
- A complete 24-hour chart retains the same bar positions as before.
