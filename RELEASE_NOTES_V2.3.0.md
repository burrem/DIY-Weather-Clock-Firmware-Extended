# V2.3.0

## More compact pressure chart

- Added a dedicated 3x5-pixel font for the pressure screen.
- Moved current pressure, delta, minimum and maximum into the top row.
- Replaced the `D` abbreviation with a dedicated delta symbol.
- Added two blank pixels between each label/icon and its value.
- Reduced the Y-axis width and moved timeline labels into the final five rows,
  giving the chart substantially more drawing area.
