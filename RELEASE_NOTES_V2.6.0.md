# V2.6.0

## Russian OLED language

- Added an English/Russian display-language selector to the configuration page.
- Requests Russian weather descriptions from wttr.in when Russian is selected.
- Added a compact complete Cyrillic 5x7 alphabet with UTF-8 decoding.
- Displays Russian weather descriptions and full weekday names; compact `MIN`/`MAX`
  pressure labels remain English for readability.
- Long Russian conditions are limited to 21 glyphs with an ellipsis.
- The web configuration interface remains English.
